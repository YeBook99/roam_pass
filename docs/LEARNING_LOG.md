# 학습 기록 (README Q7 · 배포 "막혔던 지점"의 원재료)

> 과제는 "짧은 시간에 어디까지 습득할 수 있는가"를 본다. 처음 써 본 것, 막힌 곳, AI가 틀린 순간을 **그때그때** 적는다.
> 나중에 기억으로 쓰면 구체성이 사라진다. 한 항목 3~5줄이면 충분하다.
>
> - **본문은 본인이 쓴다.** Claude는 "AI가 틀린 순간 후보"에만 사실(무엇을 제안했고 무엇이 틀렸는지)을 짧게 남길 수 있다.
